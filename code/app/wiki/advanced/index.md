These articles are for later. You do not need any of them in your first hour.
Each one covers one topic: what it is, when you need it, how it works in your
app, what to ask Claude, and what to watch out for. Read one when the
situation in the right-hand column comes up.

| Article | Read it when |
|---|---|
| [Checkpoints and undo](/wiki/advanced/checkpoints) | You are about to change something and want a way back, or a change went wrong |
| [Many modules on one block](/wiki/advanced/second-module-same-block) | You want a second list like People or Tasks, such as Accounts or Hiring |
| [Finding your way in the code](/wiki/advanced/reading-the-code) | You want to know which file does what, so you can steer Claude |
| [Changing a block](/wiki/advanced/changing-a-block) | A change cannot be made in a module file and needs the screen itself to change |
| [Skills](/wiki/advanced/skills) | You keep asking Claude for the same job and want it done the same way each time |
| [Taking a newer kit](/wiki/advanced/kit-updates) | A newer version of the kit is out and you want its fixes without losing your changes |
| [Working with a mentor](/wiki/advanced/mentors) | You are stuck, or want a power user to check your work |

## How these differ from the course

The [course](/wiki/learn) is a path: lessons in order, each with steps and a
"you are done when" check. These articles are not steps. They explain a topic
so you can decide what to ask Claude. Most end with prompts to copy and a list
of pitfalls.

If you have not finished lesson 7 yet, start with the [course](/wiki/learn).
If you are looking for a single job, such as adding a column, try
[Guides](/wiki/guides) first.
