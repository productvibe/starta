# Starta

A starter kit for your own work app: your goals, tasks and people, with a
structured interface on top, which you build on with Claude. It runs on your
own machine.

Start an app:

```
npx github:productvibe/starta init my-work
```

Pick the modules and the look on [starta.dev](https://starta.dev), which gives
you the command to run.

- `code/`: the kit, the app every Starta app starts from
- `cli/`: the `starta` command (`init`, `list`, `add`, `remove`, `update`, `apply`)

This repo is published from Starta's own repo, so pull requests are copied
across by hand.
